# Agent Orientation: tmuxinator

This package owns tmuxinator project session definitions.

## What It Owns

- `.config/tmuxinator/rk-ui-dev.yml`, a session layout for the historical
  `~/source/ruckus` workspace.

## Install Notes

- Installed with `./install.sh tmuxinator`.
- There is no package hook.

## Change Notes

- Treat paths and commands as machine/project-specific.
- Do not modernize old workspace names unless the user asks.
